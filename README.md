🚌 SLTB Asset Management & Survey App

A modern mobile application developed for the Sri Lanka Transport Board (SLTB) to digitally manage, inspect, and monitor the condition of buses and other physical assets. This application is built using Flutter and powered by Firebase to ensure real time data handling and secure operations.


🌟 Key Features

•	User Authentication

•	Secure login and registration system using Firebase Authentication.

•	Interactive Dashboard

•	Displays real-time statistics of operational assets and assets requiring maintenance.

•	Asset Surveying

•	Digital forms to record asset conditions such as Working, Faulty, and Under Repair.

•	Photo Evidence

•	Capture images using the device camera or upload from the gallery as proof of asset condition.

•	Dark Mode & Theming

•	Supports both Light and Dark modes with dynamic theme switching using Provider.

•	Multi-language Support

•	User interface supports both English and Sinhala languages.

•	Secure Settings

•	Includes password reset and basic account management features.


🛠️ Technology Stack

•	Frontend: Flutter & Dart

•	Backend: Firebase (Authentication & Cloud Firestore)

•	State Management: Provider

•	Device Features: Image Picker (Camera & Gallery Access)
